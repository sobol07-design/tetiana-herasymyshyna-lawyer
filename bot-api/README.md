# Telegram webhook для Vercel

Ізольований стартовий проєкт: Vercel Function у регіоні Frankfurt (`fra1`), без бази даних. Він не змінює статичну збірку сайту.

## Потік даних

1. Користувач відкриває бота з сайту через deep link із кодом напряму.
2. Бот показує повідомлення про передачу даних і кнопки згоди/відмови. Після згоди Тетяна отримує напрям, Telegram ID та доступні дані профілю.
3. Щоб передати текст звернення, користувач надсилає його одним повідомленням із `/send`, наприклад `/send Потрібна консультація щодо спадщини.` Саме ця команда разом із текстом є активною дією для передачі змісту.
4. Функція пересилає вміст Тетяні, не записуючи його в базу чи application logs, і після успішної передачі просить Telegram видалити вхідне повідомлення користувача.
5. Тетяна вручну видаляє копію сповіщення зі свого чату з ботом не пізніше 30 календарних днів після завершення первинного контакту. Це запропонований операційний строк, який слід повідомити Тетяні й застосовувати після її погодження.

Стан між викликами не зберігається. Повідомлення з `/send` не має автоматично прикріпленої категорії; Тетяна зіставляє його за Telegram ID зі сповіщенням про згоду. Якщо Telegram повторно доставить webhook після помилки, сповіщення може дублюватися: запитів користувачів функція не зберігає для дедуплікації.

## Розгортання

1. У Vercel створити окремий проєкт із наявного Git-репозиторію й задати Root Directory `bot-api`. Це не змінює проєкт сайту.
2. Перевірити в налаштуваннях, що регіон функції — Frankfurt (`fra1`). Це визначає регіон виконання функції, але не є гарантією, що всі технічні метадані платформи обробляються тільки в Німеччині.
3. Додати Production environment variables у Vercel:
   - `TELEGRAM_BOT_TOKEN` — новий токен, збережений лише в Vercel;
   - `TELEGRAM_WEBHOOK_SECRET` — випадковий секрет із літер, цифр, `_` і `-`;
   - після отримання ID — `TATIANA_CHAT_ID`;
   - після публікації — `PRIVACY_POLICY_URL` із HTTPS адресою погодженої політики.
4. Спершу розгорнути лише з токеном і webhook secret. Endpoint матиме адресу `https://<окремий-vercel-домен>/api/webhook`. Викликати Telegram Bot API `setWebhook` із цією адресою та тим самим `TELEGRAM_WEBHOOK_SECRET` у параметрі `secret_token`. Токен не вводити в чат із Codex і не комітити у файли.
5. Відкрити бота з акаунта Тетяни та надіслати `/myid`; команда покаже її власний числовий ID у її особистому чаті. Тетяна має передати число власнику проєкту приватним каналом. Поки немає URL політики, решта команд відповідає, що бот налаштовується; текст звернення не пересилається.
6. Додати `TATIANA_CHAT_ID`, опублікувати погоджену політику, вказати `PRIVACY_POLICY_URL` та перерозгорнути.
7. У BotFather додати команду `/send` до наявних `/start`, `/general`, `/help`, `/contact`. За бажанням додати `/myid` як допоміжну команду.
8. Перевірити з тестовим користувачем: відмова не сповіщає Тетяну; згода надсилає джерело й профіль; звичайний текст не пересилається; `/send текст` надсилається; текст після успішної передачі зникає з чату з ботом; випадковий Telegram ID не отримує адміністративних повідомлень.
9. Після перевірки замінити всі `start` URL на сайті на затверджені deep links.

## Налаштування, які ще потрібні

- Telegram ID Тетяни для `TATIANA_CHAT_ID` (команда `/myid` показує його лише в її власному чаті з ботом).
- Окремий Vercel-проєкт/домен і доступ до налаштувань Vercel.
- Новий токен бота та webhook secret у Vercel Environment Variables. Не надсилайте їх у чат.
- Погодження Тетяною запропонованого 30-денного строку очищення її Telegram-сповіщень.
- Публічна адреса погодженої політики приватності.

## Межі стартового варіанта

- Не використовує базу даних і не створює історію звернень у власній системі.
- Не приймає документи чи вкладення; надсилає лише текстові `/send` запити до 600 символів. Телефон користувач може вказати в цьому повідомленні за власним бажанням.
- Видаляє повідомлення користувача з приватного чату після успішної передачі. Якщо Telegram відмовить у видаленні, бот попросить користувача зробити це вручну.
- Не виконує автоматичне очищення копії в чаті Тетяни через 30 днів; це ручна дія Тетяни. Telegram Bot API дозволяє боту видаляти повідомлення у приватному чаті лише поки їм менше 48 годин.
- Vercel зберігає власні технічні журнали за правилами обраного тарифу. Код не записує в application logs тіло повідомлень і персональні дані.
